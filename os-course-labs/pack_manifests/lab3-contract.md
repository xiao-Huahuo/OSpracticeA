# lab3 · 能力目标与接口约定（内存管理：物理页分配与 SV39 页表）

> 本实验为每个进程构建独立的虚拟地址空间：实现物理页分配器与 SV39 三级页表机制。
  同时重构完善 lab2 中的阶段性简化实现——将用户空间指针由直接解引用改造为安全的受控内存拷贝（copyin/copyout 等价实现）。
  这也是针对系统历史代码进行规范重构与回归测试的实践单元：掌握利用 git bisect 定位引入缺陷的代码提交。

## 1. 能力目标（由你设计并实现）

1. 物理页分配器：实现空闲链表（或等价空闲管理结构），按 `LAB3_ALLOC_ORDER`
   （升序/降序/中点）顺序分配物理页；系统可用内存上限 = 总页数 − `LAB3_MEMCAP_DELTA`。
2. SV39 三级页表：实现 walk/mappages/uvm 等核心虚拟内存操作函数（**命名可自定**——
   重点在于页表遍历语义、映射建立与异常回滚不变式）。
3. 内核自身地址空间映射：UART、CLINT 等外设与内核代码段经内核页表正确可达（kvmmake 等价实现）。
4. 用户进程地址空间装配：为首个用户进程正确映射代码段、数据段、trapframe 页面及保护页
   （`LAB3_GUARD_PAGES`，其插入位置与防溢出机制由学生在设计笔记中明确）。
5. 受控内存拷贝函数（copyin/copyout 等价实现）：全面替代 lab2 中的内核直接解引用操作，
   实现跨页安全检查与用户地址合法性验证。

## 2. 接口约定与核心规范

1. **PTE 页表项语义**：V/R/W/X/U/A/D 各标志位的含义遵循 RISC-V 架构硬件规范；
   A/D 位由硬件自动置位还是软件维护由体系结构与设计决定，但在页表 dump 观测中必须真实准确反映。
2. **satp 寄存器切换规范**：进入用户态前与返回内核态后的地址空间切换协议，
   必须与 trampoline.S 中的 `userret(tf, satp)` 参数传递机制严格保持一致。
3. **页表观测输出规范**：dump_pagetable 必须严格按照预置规范 `dump_pagetable-ABI.md`
   所定义的格式输出（自动化测试脚本将按指定前缀进行匹配）。
4. **功能回归测试规范**：虚拟内存机制改造完成后，`support/../lab2` 下的 inject_uart shell
   自动化交互测试必须依然全部通过——保证引入页表后不破坏现有的中断与控制台机制。

## 3. 设计决策（设计笔记必须明确回答；现场验收重点考查）

- **mappages 映射失败时的回滚处理机制**（本实验核心考查点）：
  当分配多级页表中间页失败时，如何安全清理已分配的部分物理页？内存管理不变式如何维护？
- guard page（防溢出保护页）的权限位设置与访问异常判定路径；确保非法越界访问时触发进程终止而非导致内核崩溃。
- 内存物理配额上限的记账与统计结构；物理页耗尽时的错误码传递与系统自洽状态。
- 对 lab2 直接解引用代码的改造策略：逐字节安全拷贝、按字对齐批量拷贝还是页表校验法？
- 进程控制块（struct proc）的数据结构演进（proc_pagetable 字段的生命周期与组织方式）。

## 4. 预置支撑代码与规范（gifts/，保持只读）

`dump_pagetable-ABI.md`（页表观测格式统一规范）。本实验不提供内核端页表支撑代码，
物理内存分配与三级页表管理全部由学生独立设计与实现。

## 5. 里程碑自检

1. dump_pagetable 的输出与 lab0 所绘地址空间快照图逐项对应，能准确解释每一处权限位；
2. fork 与 exec 成功切换至新的虚拟内存映射路径，spin 与 sh 程序可并发稳定运行；
3. 越界访问或触碰保护页时触发非法缺页异常并被内核安全终止进程，内核保持完好；
4. **功能回归**：重新运行 lab2 的 inject_uart 测试会话，各项测试全部通过；
5. 代码自查：在系统调用与内核处理路径中，彻底消除任何直接解引用用户指针的行为
   （通过 grep 自查并在设计笔记中列出验证结果）。

## 6. 代码重构与调试实践方法（说明书同步章节）

- lab2 中允许的直接解引用临时方案在此阶段必须全面重构；重构前建议执行 `git tag lab3-start` 打上版本标签。
  若重构后发生系统异常，推荐使用 `git bisect start lab3-submit lab2-submit` 快速排查并精确定位
  是前期历史遗留缺陷还是本次重构引入的新问题。
- 课程答疑侧重于实验环境与体系结构规范，学生应独立承担自身代码设计与缺陷排查责任。

## 7. 耗时参考

方案设计约 6 学时 / 编码调试约 12 学时（内存管理为系统核心重难点，建议参考说明书分层步骤递进实现）。
