# lab5 官方用户态测试集（课程组提供 · 评分参考）

构建方式：内嵌方式构建，在 `UPROGS` 中追加 `zerocopy cowpair`。
前置条件：lab5 核心功能已实现（写时复制 fork、缺页异常细分处理、物理页计数系统调用 sys_pmc）。
本增量包提供的 user.h、usys.pl 与 kernel/syscall.h 中已包含 `SYS_pmc=26`
（与 lab4 的 SYS_schedstat=23 等系统调用累积），请以包内版本为准。

| 测试程序 | 测试覆盖范围 | 判定合格标准 |
|---|---|---|
| `zerocopy` | 写时复制延迟拷贝断言 | fork 后立即调用 exec，实际物理页复制增量 ≤ 2，控制台打印 `T5-1 PASS` |
| `cowpair` | 配对写入与页面引用对账 | 共享引用计数大于 0、进程间数据完全隔离、实际写入触发且仅触发对应页面复制（增量恰为 2），打印 `T5-2 PASS` |

说明：上述两项测试均为通用的系统不变式验证；`LAB5_COW_BUDGET` 复制配额耗尽后的
降级行为因具体设计而异（接口规范允许返回错误或继续运行），不作自动化硬性断言，由教师在现场答辩中根据学生设计笔记进行核验。
