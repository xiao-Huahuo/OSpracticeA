# lab7 Bugbank 故障诊断题库与试卷生成工具

本目录为 lab7（综合排错与系统诊断）的系统缺陷案例库与试卷自动生成工具。

### 1. 目录结构
- `bugbank.py`：试卷组装与题目生成管理脚本；
- `cards/`：典型系统缺陷案例库（包含 T01–T06 典型操作系统深层缺陷，覆盖 trap、memory、sched、fs 四大核心模块）。

### 2. 常用管理命令
```bash
# 校验题库字段合规性与完整性
python3 tools/bugbank/bugbank.py validate

# 针对指定学号生成排错考卷（随机抽取 3 道题目，生成包含根因答案的教师存档卷）
python3 tools/bugbank/bugbank.py assemble --sid 20230101 --out exams/

# 按照学生名单批量生成全班排错考卷
python3 tools/bugbank/bugbank.py assemble --roster roster.txt --out exams/
```

### 3. lab7 故障排查考核实施流程（衔接教学日历第 13–14 周）
1. **第 13 周实验课下半场（题目抽取与发布）**：教师在本目录执行 `bugbank.py assemble --roster roster.txt --out exams/`，一键生成全班个性化故障排查考卷（每名学生抽取 3 道题目，覆盖 ≥2 个系统层次，合理搭配难易度，基于学号哈希确定性生成——同题可复现、跨学生可查重）；
2. **题目下发**：将 `exam-<学号>.json` 中的 `symptom`（故障现象描述）与 `detection`（排查引导提示）发布给学生（**严禁下发 `root_cause` 故障根因**）；学生根据题目线索开展系统排错，课后提交故障诊断报告；
3. **第 14 周（现场答辩与口试验收）**：教师依据包含 `root_cause` 的参考答案存档卷，参照《04-现场验收题库与对错例速查手册》lab7 的因果推理链标准进行现场口试考查；验收成绩记入《现场验收定档登记表》；
4. **特殊情况处理**：若某生抽取的题目与其系统当前实际实现进度严重不匹配，可通过 `--sid <学号>` 单独重新生成考卷（相同学号生成题目一致，可使用 `--weak <模块名称>` 调整考查模块配比）。
